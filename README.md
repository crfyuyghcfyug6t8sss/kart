# كارت — موقع إصدار البطاقات

موقع لإصدار بطاقات افتراضية وفعلية لعملائك عبر API مزوّد البطاقات (cards-api).
مبني بـ Next.js 15 و TypeScript وقاعدة SQLite المدمجة في Node (`node:sqlite`).

## ما الذي يفعله

- **حسابات المستخدمين:** تسجيل ودخول بكلمة مرور (scrypt) وجلسات بكوكي آمنة. كل مستخدم يُسجَّل تلقائياً لدى المزوّد ويُحفظ `uid` الخاص به.
- **التحقق من الهوية (KYC):** نموذج كامل مع رفع المستندات، ويطلب مستنداً إضافياً تلقائياً للدول التي تحتاجه.
- **البطاقات:** إصدار بطاقة افتراضية أو فعلية (مع عنوان الشحن)، عرض الرقم و CVV عند الطلب فقط، شحن، سحب، تجميد، إلغاء، وسجل العمليات.
- **البطاقة الفعلية:** تتبع الشحن، التفعيل، تعيين وعرض الرقم السري (مشفّر بـ AES)، وحد الدفع بدون رقم سري.
- **الإشعارات (Webhooks):** `POST /api/webhooks/cards` يتحقق من التوقيع (HMAC-SHA256)، ويتجاهل الإشعارات المكررة بـ `eventId`، ويحدّث حالة الشحن والسحب، ويعرض طلبات 3DS على صاحب البطاقة للموافقة أو الرفض.
- **الإدارة (`/admin`):** أرصدة التاجر، المنتجات، محاكاة العمليات في بيئة الاختبار، وسجل الإشعارات. متاحة فقط للبريد المذكور في `ADMIN_EMAILS`.

## التشغيل

يتطلب Node.js 22.13 أو أحدث.

```bash
npm install
cp .env.example .env   # ثم املأ القيم من لوحة التاجر
npm run dev            # http://localhost:3000
```

للإنتاج: `npm run build && npm start`.

### إعداد الإشعارات

في لوحة التاجر ضع رابط الإشعارات:

```
https://<your-domain>/api/webhooks/cards
```

## الاختبارات

```bash
npm test        # يتحقق من التوقيع وتشفير الـ PIN والـ webhook مقابل الأمثلة المنشورة في التوثيق
npm run typecheck
```

## ملاحظات مهمة عن الـ API

- **التوقيع v2:** الـ headers المرتبة (مع `uid` حتى لو كان فارغاً) تُلصق مباشرة بالـ body المرتب **بدون `&` بينهما**، وهذا مطابق لمثال التوثيق ومُختبر في `tests/signing.test.ts`.
- **مفتاح الـ webhook** يُستخدم كنص كما هو (UTF-8) وليس بعد فك Base64، بعكس مفتاح الـ PIN.
- **الشحن والسحب غير متزامنين:** النتيجة تصل بالـ webhook أو بزر "تحديث" في صفحة البطاقة.
- **أموال الشحن تُخصم من رصيد التاجر.** قبل الإطلاق الفعلي يجب ربط بوابة دفع لتحصيل المبلغ من العميل قبل استدعاء الشحن.
- **لا تضع المفاتيح في git أبداً.** ملف `.env` مستثنى في `.gitignore`.
